# WhatsApp-Automation-Project
Built a WhatsApp automation system that handles customer orders, FAQ responses, and inventory checks in real time. Supports multilingual communication and automates order processing to reduce manual work.
<img width="1046" height="396" alt="image" src="https://github.com/user-attachments/assets/5a238e60-c145-4ffd-bb8d-c9ad9641a02e" />
I built a WhatsApp chatbot for a restaurant. Customers can chat with the bot to ask questions or place orders. The bot checks the restaurant's inventory, only allows available items to be ordered, answers FAQ questions, and automatically sends confirmed orders to the restaurant team. It also supports multiple languages to provide a better customer experience.
<img width="560" height="482" alt="image" src="https://github.com/user-attachments/assets/91be0f34-c7b7-461f-aa78-b8f987b3a3d2" />
The chatbot answers customer queries, provides FAQ-based responses, checks item availability from inventory before accepting orders, and supports multilingual conversations. It automatically captures order details and sends confirmed orders to the restaurant system, helping reduce manual effort and improve customer experience.
